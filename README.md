# hxwl-05 水族箱水质监测

多鱼缸长期水质养护台账：检测留痕、换水登记、异常提醒按单项跟踪。

## 技术栈

React + Vite + TypeScript + CSS（数据持久化用浏览器 localStorage，无需后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **每缸独立安全范围**：pH、氨氮、亚硝酸盐、硝酸盐、硬度、温度六项指标，
  可在「鱼缸与安全范围」里按缸设置上下限，并可新增鱼缸（名称/类型/容积）。
- **水质检测登记**：选择检测时间、登记人，按项填值，留空表示本次未检测；
  填值时实时对照本缸范围标出越界。保存后弹出本次「新增/解除提醒」结果。
- **待处理提醒（按「缸 + 单项指标」跟踪）**：
  - 检测值越界自动开提醒，看板和顶部横幅汇总所有待处理项；
  - 只有该缸同一指标的后续检测回到安全范围，对应提醒才解除；
  - 某项单独恢复不会清掉同缸其他异常；本次未检测的指标，其异常继续挂起；
  - 换水登记不会自动解除异常，需换水后复测回范围才解除。
- **换水登记**：记录时间、实际水量（升）、登记人和备注，自动按缸体容积换算百分比。
- **看板**：按每只缸最新一次检测展示状态（正常 / 异常 N 项 / 暂无检测）、
  各指标最新值和最近换水时间。
- **台账记录**：每只缸全部历史检测、换水、异常生成与解除事件可追溯，
  可按「检测 / 换水 / 异常提醒」筛选；异常解除时同时保留触发起始值和复测值。
- **交接班**：当班登记人姓名本地记忆，自动带入每条新记录。
- **导出备份**：一键下载完整台账 JSON，方便归档或跨机迁移。

首次打开会写入示例数据（草缸A / 海缸B / 繁殖缸C），之后所有录入长期保存在本机浏览器中。

## 目录结构

```
src/
  types.ts        台账领域模型（鱼缸 / 检测 / 换水 / 异常）
  domain.ts       安全范围判定、异常开关规则、最新记录查询
  storage.ts      localStorage 读写、首次种子、导出备份
  seed.ts         示例数据（异常由检测记录推导，与真实流程一致）
  format.ts       时间与数值格式化
  components/     看板、检测/换水表单、台账视图、安全范围设置
scripts/verify.ts 业务规则校验脚本（npx esbuild 打包后 node 运行）
```
