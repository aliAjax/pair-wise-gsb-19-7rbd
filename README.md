# hxwl-05 水族箱水质监测

多鱼缸水质台账：检测登记、换水登记、异常指标待处理提醒。

## 技术栈

React + Vite + TypeScript + CSS，数据持久化在浏览器 localStorage（可导出 JSON 备份）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **看板**：按每只鱼缸最新一次检测显示状态（正常 / 待处理 / 暂无检测），列出当前越界项、上次换水
- **检测登记**：按缸录入 pH、氨氮、亚硝酸盐、硝酸盐、温度，未测项目留空；越界项实时标红
- **换水登记**：记录换水量（升）、比例和时间
- **鱼缸与范围**：每只鱼缸独立的安全范围，可新增鱼缸、逐项调整范围
- **历史台账**：全部检测、换水、提醒记录合并时间线，按鱼缸和类型筛选，旧记录长期可查

## 提醒规则

- 检测值越界 → 该缸生成一段"待处理提醒"，记录每个越界项的首次越界时间与最近值
- 之后的检测中某项回到范围内 → 只移除这一项，其余异常保留；未复测的项目维持原状态
- 全部越界项都回到范围内 → 提醒自动解除（解除记录仍保留在历史台账中）
- 提醒由检测记录按时间重放推导（`src/ledger.ts` 的 `buildAlertEpisodes`），补录旧记录也会算对
